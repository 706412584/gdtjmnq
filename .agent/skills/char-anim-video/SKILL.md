# 角色动画视频生成

## 核心原则

视频模型四个坏习惯必须压制：
1. 镜头移动 用first_last_frame同图锁首尾
2. 背景污染 prompt强调纯白FFFFFF不变
3. 凭空加特效 prompt禁止一切特效
4. 角色出画布 prompt要求动作克制始终完整在画面内

## 模式选择

原地动作(待机/受击/死亡/攻击/施法/跳跃) → first_last_frame 同图作首尾帧
位移动作(行走/奔跑/冲刺) → first_frame

## 通用参数

ratio:"1:1" duration:5 generate_audio:false resolution:"720p"

## Prompt固定前缀
固定机位,镜头完全不动,无任何缩放平移推拉。纯白色背景,背景自始至终保持纯白不变,无阴影无渐变无地面无任何背景元素。禁止任何特效粒子光效火花魔法圈,画面只有角色身体动作。角色始终完整呈现在画面中央,动作幅度克制,身体任何部位不得超出画布边缘被裁切。

## 各动作描述(拼在前缀后)

待机: 角色原地站立不动,仅身体极轻微上下呼吸起伏,幅度极小
行走: 角色原地踏步行走循环,双腿小幅交替迈步,手臂自然摆动
奔跑: 角色原地快速跑步,手臂摆动,身体微前倾,动作不超出身体轮廓
攻击: 角色原地小幅度挥动武器,动作紧凑不夸张,攻击后回到站姿
受击: 角色原地身体小幅度后仰晃动,然后恢复站姿,不超出身体范围
死亡: 角色原地缓慢倒下,身体瘫软但保持在画面中心区域内
跳跃: 角色原地小幅跳起后落地,跳跃高度克制不超出画面顶部

## 注意事项

1. 背景默认纯白,可改其他纯色但必须强调自始至终不变
2. 默认5秒,死亡可缩短到3-4秒
3. 多动作可并行调用多个create_video_task
4. 角色仍出画布时加强: 动作幅度必须极小,保持在角色轮廓50%范围内,绝不允许手脚武器超出画面
5. 背景仍污染时加强: 绝不允许出现任何非角色元素,无光晕无尘土无投影无地板线
6. 施法如需光效可去掉禁止特效约束,但默认一律不加
