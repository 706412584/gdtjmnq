# 古代工坊手游完整开发方案

## 1. 项目定位

- 项目代号：`Project Smith`
- 中文名：`古代铁匠模拟器`
- 副标题建议：`断剑重铸` / `千锤百炼`
- 品类：`手机端 Hybrid-Casual`，步骤解谜 + 轻经营 + 叙事收集
- 目标平台：`iOS + Android`
- 核心变现：`Rewarded Video` 为主，`Interstitial` 为辅，轻量 `IAP` 去广告 / 新手礼包 / 皮肤包
- 核心卖点：
  1. 一眼能看懂的古代工坊题材
  2. 可拆分成多个简单小游戏的步骤式铸剑流程
  3. 强烈的“从废铁到神兵”成长反馈
  4. 广告素材表现力强，前后对比明显

## 2. 核心概念

玩家扮演战乱时代一间濒临倒闭的小铁铺学徒，通过接单、采料、熔炼、锻打、淬火、研磨、镶装，逐步重建工坊并锻造名器。核心不是做硬核模拟，而是将“古代手工业”拆成一组节奏明快、反馈清晰、易于量产关卡的小玩法。

一句话描述：

`把古代铸剑工艺拆成多个 10-25 秒的爽感小游戏，再用工坊升级、名器收藏和剧情订单把玩家留住。`

## 3. 为什么选“铸剑工坊”

- 比瓷器、造纸、织布更有力度，打击感和视觉反馈更强
- 更适合短视频投放，锤打、火花、裂纹修复、神兵出炉都容易做创意
- 系统结构清楚：矿石 -> 铁料 -> 剑胚 -> 剑身 -> 成品 -> 名剑图鉴
- 易做成长线内容：兵器谱、门派订单、王朝剧情、传说材料、工匠弟子

## 4. 目标用户

- 年龄：`18-40`
- 偏好：
  - 喜欢休闲解压、手作感、经营成长
  - 对古风、美术、器物文化有兴趣
  - 可接受广告换收益，不愿意学习复杂规则
- 核心场景：
  - 通勤、睡前、碎片时间
  - 单次游玩 `2-8 分钟`

## 5. 商业目标

- D1 留存目标：`35%+`
- D7 留存目标：`10%+`
- 激励视频观看率：`25%-40%`
- 新手前 30 分钟广告展示目标：
  - `Rewarded` 3-5 次
  - `Interstitial` 1-2 次
- 设计原则：
  - 广告是提速，不是强惩罚
  - 操作成功的满足感必须先成立，广告收益再叠加

## 6. 核心玩法循环

### 6.1 单局循环

1. 接订单
2. 选择材料
3. 进入步骤小游戏
4. 结算品质
5. 获得铜钱、声望、材料、图鉴碎片
6. 升级工坊或接更高级订单

### 6.2 中循环

1. 提升熔炉、锻台、淬火池、研磨台等级
2. 解锁新配方、新材料、新装饰
3. 开启剧情人物线
4. 收集“名器图谱”

### 6.3 长循环

1. 从破旧铁铺成长为御用兵工坊
2. 完成章节主线
3. 解锁传奇材料和传世神兵
4. 形成“名剑收藏馆 + 工坊经营 + 弟子培养”的长期目标

## 7. 核心步骤玩法设计

每把武器的制作被拆成数个轻量环节，每环节独立可复用，降低开发成本。

### 7.1 选矿与除杂

- 玩法类型：`三选一识别 + 快速点击清除`
- 目标：从矿石堆里挑出高纯度矿料，去掉裂石和杂质
- 时长：`8-12 秒`
- 难度变量：
  - 杂质数量
  - 时间限制
  - 干扰矿石外观接近度

### 7.2 控火熔炼

- 玩法类型：`温度条停点`
- 目标：让炉温停在最佳熔炼区间
- 时长：`6-10 秒`
- 反馈：
  - 过火：金属发白、品质下降
  - 不足：铁液浑浊、杂质残留

### 7.3 锻打成型

- 玩法类型：`节奏点击 + 区域修形`
- 目标：在指定节拍落锤，把剑胚敲进目标轮廓
- 时长：`10-20 秒`
- 核心爽点：火花、金属回响、轮廓越来越直

### 7.4 淬火控时

- 玩法类型：`长按释放`
- 目标：判断最佳入水时机与停留时长
- 时长：`5-8 秒`
- 失败表现：
  - 太久：脆裂
  - 太短：韧性不足

### 7.5 研磨开锋

- 玩法类型：`路径拖拽`
- 目标：沿正确角度拖动磨石，使刃线平直
- 时长：`8-15 秒`
- 难点：角度偏差和耐久限制

### 7.6 装具与纹饰

- 玩法类型：`排序拼装`
- 目标：把剑格、剑柄、缠绳、鞘饰按顺序安装
- 时长：`8-12 秒`
- 强视觉回报：成品预览大幅提升收藏欲

### 7.7 特殊订单变体

- 毒刃：多一步药液浸染
- 祭器：加入铭文刻写小游戏
- 断剑修复：拼合 + 补锻 + 裂纹清理
- 帝王佩剑：多材料搭配与品质阈值

## 8. 数值与品质系统

### 8.1 核心属性

- `锋利`
- `坚韧`
- `平衡`
- `工艺`
- `稀有`

### 8.2 品质等级

- `凡品`
- `良品`
- `上品`
- `珍品`
- `名器`
- `传世`

### 8.3 品质计算

品质由以下因子构成：

- 材料基础值
- 每个小游戏表现评分
- 工坊设备加成
- 订单适配奖励
- 特殊事件加成

### 8.4 评分表现

- `Perfect`
- `Great`
- `Good`
- `Poor`

目标不是让玩家精算，而是让他感到“每一步都影响最终品质”。

### 8.5 步骤评分数值

每把武器默认包含 `4` 个有效步骤，每步按表现给分：

- `Perfect`：`1.15`
- `Great`：`1.05`
- `Good`：`0.95`
- `Poor`：`0.75`

单把武器最终品质分公式：

`FinalScore = BaseScore x MaterialCoeff x StepAvgCoeff x ToolCoeff x OrderMatchCoeff x BonusCoeff`

字段定义：

- `BaseScore`：武器配方基础值，范围 `100-600`
- `MaterialCoeff`：材料系数，范围 `0.9-1.6`
- `StepAvgCoeff`：步骤平均表现系数，范围 `0.75-1.15`
- `ToolCoeff`：设施加成，范围 `1.00-1.35`
- `OrderMatchCoeff`：订单适配，范围 `1.00-1.20`
- `BonusCoeff`：特殊客人、活动、暴击工艺，范围 `1.00-1.15`

### 8.6 品质分段

- `凡品`：`<120`
- `良品`：`120-169`
- `上品`：`170-229`
- `珍品`：`230-309`
- `名器`：`310-409`
- `传世`：`410+`

### 8.7 属性映射规则

每个小游戏主导一个主属性：

- 选矿与除杂：主要影响 `坚韧`
- 控火熔炼：主要影响 `工艺`
- 锻打成型：主要影响 `平衡`
- 淬火控时：主要影响 `锋利`
- 研磨开锋：主要影响 `锋利`
- 装具与纹饰：主要影响 `工艺` 与 `稀有`

属性展示建议不用浮点，统一映射到 `0-100`：

- `锋利 = min(100, round(FinalScore x 0.22 + StepSharpenBonus))`
- `坚韧 = min(100, round(FinalScore x 0.20 + OrePurityBonus))`
- `平衡 = min(100, round(FinalScore x 0.18 + HammerRhythmBonus))`
- `工艺 = min(100, round(FinalScore x 0.24 + DecorationBonus))`
- `稀有 = 配方稀有值 + 稀有材料值 + 特殊事件值`

首发只做 4 条武器线，避免内容爆炸：

| --- | --- | ---: | ---: | ---: |

| 长剑 | 第1章后半 | 140 | 4 | 45-60秒 |
| 重剑 | 第2章 | 180 | 4 | 55-75秒 |
| 仪礼剑 | 第3章 | 230 | 5 | 65-90秒 |

### 8.9 材料品质系数

| 材料档位 | 系数 | 获取方式 |
| --- | ---: | --- |
| 粗铁 | 0.90 | 新手默认 |
| 熟铁 | 1.00 | 常规订单掉落 / 商店 |

### 8.10 失误惩罚

- 某一步 `Poor`：该步主属性额外 `-8`
- 连续两步 `Poor`：最终品质系数再乘 `0.92`
- 关键步骤失败但看广告补救：该步结算锁定为 `Good`
- 直接放弃订单：退回 `40%` 材料，不返铜钱

## 9. 资源回环与经济系统设计

### 9.1 软货币

- `铜钱`：升级设施、购买常规材料
- `声望`：解锁章节、人物和高级订单

### 9.2 硬货币

- `玉璧`
- 来源：成就、活动、付费、少量广告奖励
- 用途：跳过等待、买稀有材料、开限定装饰

### 9.3 制作资源

- `矿石`
- `木炭`
- `磨料`
- `木材`
- `皮绳`
- `纹金`
- `稀有陨铁`

### 9.4 收集资源

- `名器图谱碎片`
- `旧时代传闻`
- `师门手札`

### 9.5 回环公式

订单 -> 小游戏表现 -> 成品品质 -> 奖励提升 -> 工坊升级 -> 可接更高价值订单 -> 解锁更好资源 -> 更多高品质成品

广告切入点嵌在回环里：

- 看广告拿双倍铜钱
- 看广告补一次失误步骤
- 看广告直接获得稀有材料
- 看广告加快工坊升级

### 9.6 核心货币单位

为避免经济膨胀，首个大版本只保留三层货币：

- `铜钱`：主循环货币
- `声望`：进度门槛货币
- `玉璧`：硬通货

不额外引入“体力”作为主门槛。体力在广告流产品里容易压掉开局体验，首发改用：

- 订单刷新次数限制
- 稀有订单出现概率
- 升级等待

### 9.10 新手前 30 分钟经济预估

目标是让玩家既有“升级得动”的感觉，又不会在 20 分钟后失去追求。

新手 30 分钟预期：

- 完成订单：`8-12 单`
- 铜钱总收入：`700-1100`
- 铜钱净结余：`220-380`
- 声望总收入：`30-55`
- 激励广告观看：`3-5 次`
- 解锁：
  - 熔炉 Lv2
  - 锻台 Lv2
  - 第2类短刀配方
  - 第1个稀有客人事件

### 9.13 广告奖励数值

激励广告收益必须显著，但不能直接击穿付费点。

建议值：

- 订单结算双倍：只翻 `铜钱`，不翻 `声望`
- 失败补救：恢复 `1` 次关键步骤
- 免费材料箱：随机给 `35-60` 铜钱价值材料
- 稀有客人刷新：保底出现 `1` 张 T3 或以上订单
- 升级加速：单次减少 `15` 分钟

### 9.14 声望节奏

声望只负责“开内容”，不参与商店直接购买，避免双货币认知混乱。

章节门槛建议：

| --- | ---: |
| 第1章 | 默认 |
| 第2章 | 40 |
| 第3章 | 120 |
| 第4章 | 260 |
| 第5章 | 480 |

### 9.15 图鉴与收藏收益

收藏不是纯装饰，要给稳定长线收益。

| 图鉴行为 | 奖励 |
| --- | --- |
| 首次打造新武器 | 铜钱 +20, 图谱碎片 x1 |
| 集齐同系列 3 把 | 声望 +10 |
| 集齐同系列 6 把 | 被动铜钱结算 +3% |
| 首次打造名器级 | 玉璧 +5 |
| 首次打造传世级 | 玉璧 +12 |

### 9.16 日常与离线收益

为了提升广告承接和回流，增加轻量日常循环：

- 每日订单 3 个
- 每日看广告奖励上限 6 次
- 离线陈列收益上限 4 小时

离线收益公式：

`OfflineCoins = 展示中武器总收藏值 x 陈列架系数 x 离线小时数 x 0.08`

例：

- 展示收藏值 `300`
- 陈列架系数 `1.2`
- 离线 `3` 小时
- 收益：`300 x 1.2 x 3 x 0.08 = 86 铜钱`

### 9.17 经济安全阈值

为避免数值崩坏，后台配置需满足：

- 新手前 20 单平均净利润率：`35%-55%`
- 广告补给价值不超过玩家当前 12 分钟产出
- 稀有材料不能在首章稳定大量获得
- `玉璧` 获取速率控制在日均 `20-35` 免费量
- 任意一次商店礼包都不能直接跳过一个完整章节

### 10.3 主线结构升级

主线不再只是线性章节，而是 `章节推进 + 阵营拉扯 + 角色关系 + 关键选择` 四线并行。

四条长期矛盾线：

1. `王朝线`
   - 王都希望垄断名器锻造，建立御用兵坊体系
2. `江湖线`
   - 门派与镖局希望名器留在民间，不受朝廷控制
3. `商会线`
   - 商人势力想掌控兵器流通，通过稀有材料赚差价
4. `匠道线`
   - 老掌柜坚持“器为人用，不为权势所役”，代表工匠独立立场

#### 第二章关键事件

- 神秘女商沈绫开始频繁上门，以高价收购破损兵器

#### 第三章关键事件

- 剑客陆沉带来一截断剑残片，请主角修复
- 门派长老与王都差役几乎同时盯上这把断剑
- 主角第一次必须在“交给谁”之间做出判断

#### 第四章关键事件

- 老掌柜过去的身份曝光，他曾参与锻造古剑

### 10.6 AVG / SLG 式推进结构

每章由三层内容组成：

1. `主线节点`
   - 必经剧情，推动大事件
2. `角色事件`
   - 与主要角色的对话、委托、私下请求
3. `地区 / 工坊经营事件`
   - 官府巡查、商队来访、物价波动、材料短缺、匠人招募

玩家每推进一个主线节点，会开放 `2-4` 个可选对话或行动事件。  
这些事件会影响：

- 角色好感
- 阵营倾向
- 工坊声望方向
- 最终结局资格

## 11. 剧情设计

### 11.1 剧情策略

- 表层保持休闲可读，底层加入分支和记忆点
- 正常玩家看的是“订单故事 + 工坊成长”
- 深度玩家能感受到“人物站队 + 道德选择 + 多结局”
- 对话尽量短句化，每段 `2-6` 句，适合移动端

### 11.2 剧情系统目标

要同时满足三件事：

1. `像 AVG`
   - 人物立得住，有对话演出，有选择分支
2. `像 SLG`
   - 选择不是纯文本，能影响资源、阵营、地图事件、订单解锁
3. `像休闲手游`
   - 不压过玩法，剧情触发频率和时长都受控

### 11.3 核心悬念

- 老掌柜为何始终不许主角碰后院残剑
- 神秘女商为何高价收购旧兵器
- 传世古剑为何断裂成数段散落各地
- 主角师承是否与失踪名匠有关
- 当年的“护国名器”究竟是救人之器，还是屠城之器

### 11.4 叙事变量系统

剧情变量只保留最关键的一组，避免脚本爆炸：

#### 角色好感

- `老掌柜信任`
- `沈绫好感`
- `陆沉好感`
- `失踪弟子认同`
- `县尉支持`

范围统一为 `-100 ~ +100`

#### 阵营倾向

- `朝廷倾向`
- `江湖倾向`
- `商会倾向`
- `匠道倾向`

范围统一为 `0 ~ 100`

#### 世界状态

- `断剑残片已收集数`
- `真相揭露度`
- `工坊名望等级`
- `韩铸敌意值`

### 11.5 变量变化规则

每个关键选择应至少影响两类变量，避免“选项只是换一句台词”。

例：

- 接官府急单：
  - `朝廷倾向 +8`
  - `匠道倾向 -3`
  - `县尉支持 +10`
- 帮陆沉隐瞒断剑下落：
  - `江湖倾向 +10`
  - `沈绫好感 -4`
  - `真相揭露度 +1`
- 拒绝沈绫的高价收购：
  - `匠道倾向 +8`
  - `商会倾向 -6`
  - `工坊名望等级` 获得隐藏加成

### 11.6 单关叙事模板

1. 委托人出场
2. 提出需求与背景
3. 给玩家一个态度选择
4. 制作过程穿插一句风险提示
5. 成品交付后按品质触发反馈
6. 根据前置变量决定额外对话
7. 写入角色关系或阵营变化

### 11.7 对话表现形式

建议采用：

- `半身角色立绘`
- `底部双行对话框`
- `右上角关系变化提示`
- `关键选项出现时暂停背景动效`

选择按钮只保留 `2-3` 个，避免移动端点选负担。

选项类型：

- `态度类`
  - 强硬 / 委婉 / 沉默
- `立场类`
  - 交给官府 / 交给门派 / 自己留下
- `利益类`
  - 收高价 / 讲规矩 / 先帮急用之人
- `感情类`
  - 信任 / 怀疑 / 试探

### 11.8 主角人格塑造

主角不是空白模板，而是“可偏移的人”：

- 初始设定：
  - 有匠心
  - 急于证明自己
  - 对权势天然警惕
- 玩家选择会逐步把主角推向三种气质：
  - `实用派`
  - `名利派`
  - `守道派`

这三种人格不会替代结局，而是影响同一结局里的台词与姿态。

### 11.9 关键角色深化

#### 老掌柜

- 外显：嘴硬、保守、爱骂人
- 内里：背着旧案，怕主角重走自己的路
- 个人线主题：`匠人是否该为错误的时代负责`

#### 沈绫

- 外显：精明、漂亮、会说话
- 内里：并非纯反派，她要控制兵器流通，是因为见过乱世失控
- 个人线主题：`秩序和自由，哪个更像善`

#### 陆沉

- 外显：冷静寡言，办事利落
- 内里：宗门与个人信念并不完全一致
- 个人线主题：`复仇是否值得以更多人流血为代价`

#### 韩铸

- 外显：商业对手，嘴脸现实
- 内里：他相信工坊只有投靠强权才能活
- 个人线主题：`活下去和活得正，到底哪个更重要`

#### 失踪弟子

- 外显：神出鬼没，掌握古剑线索
- 内里：既是背叛者，也是当年真相幸存者
- 个人线主题：`背叛到底是贪婪，还是求生`

### 11.10 主线五章剧情大纲

#### 第一章：破铺开张

剧情目标：

- 让玩家认识工坊困境
- 埋下断剑、残卷、老掌柜隐瞒三条线索

核心选择：

1. 第一笔收入用于修炉还是还债
2. 是否接官府压价订单
3. 是否偷看老掌柜藏起的残卷

章节结尾：

- 玩家第一次确认这间铺子并不普通

#### 第二章：街坊名声

剧情目标：

- 建立地方关系网
- 引入沈绫与韩铸

核心选择：

1. 帮穷苦猎户插队，还是先做富户高价单
2. 是否把一把旧刀卖给沈绫
3. 面对韩铸挖人，是抬价抢人还是按规矩留人

章节结尾：

- 沈绫拿出一段与残卷匹配的剑纹拓片

#### 第三章：门派来信

剧情目标：

- 正式进入阵营冲突
- 让陆沉成为长期伙伴

核心选择：

1. 断剑残片先交给谁
2. 是否答应替陆沉隐瞒行踪
3. 官府追查时是配合还是拖延

章节结尾：

- 古剑并非单纯名器，而是一把曾改变政局的兵器

#### 第四章：古剑残卷

剧情目标：

- 揭示老掌柜过去
- 让玩家知道真正的历史版本

核心选择：

1. 是否公开老掌柜身份
2. 是否放走失踪弟子
3. 是否把修复中的古剑交给外人检验

章节结尾：

- 玩家意识到所有人都在争“剑”，但真正危险的是“谁定义这把剑”

#### 第五章：御用之争

剧情目标：

- 汇总所有分支
- 让玩家公开站队并锻出最终名器

核心选择：

1. 皇家器试上使用哪种锻造理念
2. 古剑完成后献给谁
3. 是否公开旧案真相

章节结尾：

- 进入多结局分支

### 11.11 支线设计框架

支线分为四类：

#### 角色支线

- 沈绫的私运线
- 陆沉的复仇线
- 老掌柜的旧案线
- 失踪弟子的逃亡线

#### 市井支线

- 穷人修农具
- 富户炫耀兵器
- 婚礼礼剑
- 守城临时征器

#### 工坊支线

- 学徒招募
- 原料断供
- 工坊失火
- 锻台损坏

#### 秘闻支线

- 古剑残铭解读
- 废墟寻片
- 旧兵谱收集
- 前朝匠谱流出

### 11.12 支线与系统绑定

支线不是纯剧情，要绑资源和系统：

- 完成`穷人修农具`：
  - 铜钱少
  - 匠道倾向高
  - 街坊口碑提升
- 完成`富户炫耀兵器`：
  - 铜钱多
  - 商会倾向提升
  - 部分平民角色好感下降
- 完成`守城临时征器`：
  - 朝廷倾向提升
  - 可开官府订单池
- 完成`废墟寻片`：
  - 获得断剑残片
  - 推进真相揭露度

### 11.13 关键选择示例

#### 选择示例 1：县尉压单

场景：

县尉要求主角先做官府兵器，压价但承诺日后照应。

选项：

1. `接下，先活下来再说`
   - 朝廷倾向 `+10`
   - 县尉支持 `+12`
   - 铜钱立即 `+60`
   - 匠道倾向 `-4`
2. `按正常工价做，不赊不欠`
   - 匠道倾向 `+8`
   - 县尉支持 `-8`
   - 工坊名望 `+1`
3. `婉拒，先做街坊急单`
   - 朝廷倾向 `-6`
   - 街坊口碑 `+1`
   - 后续可能触发官差刁难事件

#### 选择示例 2：沈绫高价收剑

场景：

沈绫愿意出高价买下一把带古纹的旧剑。

选项：

1. `卖`
   - 铜钱 `+120`
   - 沈绫好感 `+10`
   - 真相揭露度 `-1`
2. `不卖`
   - 匠道倾向 `+8`
   - 沈绫好感 `-6`
   - 后续开启私下追查支线
3. `假卖，暗中留样`
   - 沈绫好感 `+3`
   - 真相揭露度 `+1`
   - 若后续被发现，关系大跌

#### 选择示例 3：陆沉复仇

场景：

陆沉想借你锻的剑去杀当年仇人。

选项：

1. `帮他`
   - 陆沉好感 `+12`
   - 江湖倾向 `+10`
   - 后续触发血债分支
2. `劝他放下`
   - 陆沉好感 `-5`
   - 匠道倾向 `+6`
   - 可开和解路线
3. `只借剑，不问去向`
   - 陆沉好感 `+4`
   - 主角人格向实用派偏移

### 11.14 多结局设计

首发建议做 `5 个主结局 + 6 个角色后日谈`。

#### 结局 A：御用神匠

条件建议：

- 朝廷倾向最高
- 县尉支持或王都支持达到阈值
- 第五章公开参加器试并献剑

结果：

- 工坊成为皇家御坊
- 财富和名声最高
- 但主角失去部分自由

#### 结局 B：江湖名坊

条件建议：

- 江湖倾向最高
- 陆沉线完成
- 古剑未交朝廷

结果：

- 工坊成为江湖各派信赖的兵坊
- 朝廷持续打压
- 玩家保住独立声望

#### 结局 C：商会铸局

条件建议：

- 商会倾向最高
- 沈绫好感高
- 多次选择高价单与流通优先

结果：

- 工坊发展最快，财富最高
- 名器成为商品而非信物
- 道德评价偏灰

#### 结局 D：守道匠宗

条件建议：

- 匠道倾向最高
- 老掌柜线真相完成
- 公开旧案并拒绝献剑

结果：

- 主角带着工坊远离权势中心
- 工坊规模不一定最大，但匠名最正
- 属于高评价精神结局

#### 结局 E：断火残坊

条件建议：

- 韩铸敌意过高
- 多个关键角色关系断裂
- 真相未完整收集
- 第五章站队失败

结果：

- 工坊被吞并或被迫关闭
- 主角带一把未成之剑离开
- 作为失败结局存在

### 11.15 角色后日谈

主结局之外，用角色后日谈增强 AVG 感：

- `沈绫后日谈`
  - 成为盟友 / 离去 / 反目
- `陆沉后日谈`
  - 复仇成功 / 放下仇恨 / 战死未归
- `老掌柜后日谈`
  - 释怀 / 避世 / 替主角承担后果
- `失踪弟子后日谈`
  - 回归 / 消失 / 成为下一代对手

### 11.16 剧情节奏控制

要防止剧情过重压玩法，按这个比例控制：

- 普通订单：`15-30 秒文本`
- 角色事件：`45-90 秒文本`
- 主线节点：`90-180 秒文本`
- 关键抉择：`20-40 秒`

单次连续剧情不得超过 `3 分钟`，超过就切回可操作环节。

### 11.24 分支控制原则

为了避免脚本量失控，执行时必须遵守：

1. 每章只有 `2-3` 个真正改变路线的大选择
2. 其他选择主要影响角色好感、资源和短期事件
3. 结局判定只看少数核心变量，不做几十个隐藏分叠加
4. 角色支线允许共存，但主结局只能归属一个主阵营
5. 第一章只做“埋线和轻分支”，从第三章开始才做重站队

### 11.31 剧情生产建议

要把这套剧情真正做出来，生产顺序建议固定：

1. 先锁 `变量字典`
2. 再锁 `主结局条件`

- 不在步骤小游戏中间打断

- `6 元去广告`
- `12 元新手锻造礼包`
- `30 元传奇工坊皮肤`
- `限时名器图鉴通行证`

### 12.4 广告友好设计原则

- 广告必须是“再来一次更爽”
- 看广告后的奖励要立刻可见
- 奖励尽量作用于当前目标，不给太抽象的货币

- `GameFlow`
  - 启动、章节、订单、结算状态流转
- `MetaSystem`
  - 工坊、货币、升级、图鉴
- `MiniGameSystem`
  - 各步骤小游戏逻辑
- `NarrativeSystem`
  - 对话、人物关系、章节触发

## 24. MVP 范围

MVP 只做这些：

- 1 个主城
- 1 套工坊升级
- 3 个核心小游戏
- 20 个订单
- 2 名主要角色
- 1 章剧情
- 1 套广告系统
- 1 套图鉴收藏

不要在 MVP 加入：

- 复杂弟子系统
- 装备穿戴
- 多兵种战斗
- 大地图探索
- 联网玩法

## 25. 风险与规避

### 25.1 风险

- 题材有辨识度，但如果交互不够爽，容易显得慢
- 古风题材若太厚重，会压低休闲用户转化
- 步骤过多会增加疲劳感

### 25.2 规避方案

- 单局只保留 3-4 个步骤，其他用自动结算或后期解锁
- 每一步操作控制在 `5-15 秒`
- UI 与剧情都保持轻量，不走重文本路线
- 广告奖励尽量绑定当前失败点

## 26. 可扩展方向

- 从铸剑扩展到铸甲、造弓、修古器
- 节日限时活动：灯会佩剑、将军庆典、王城器试
- 收藏馆展示玩法
- 名器故事簿
- 工坊装修竞赛

## 27. 最终立项建议

如果你要的是：

- `手机端`
- `开发难度可控`
- `广告流友好`
- `历史题材`
- `有脑洞但不离谱`

那么最稳的切入方式不是做“大历史模拟”，而是做：

`古代铸剑工坊 + 步骤解谜 + 轻经营 + 名器叙事`

这套组合具备：

- 足够明确的广告展示力
- 明确的中短期循环
- 可拆分的低成本小游戏结构
- 强视觉成长反馈
- 适合 AI 辅助生产资源

它不是最复杂的方案，但很可能是最容易做出能跑广告验证版本的历史题材手游。

### 28.3 订单库生成规则（内容向）

```md
# 订单库生成规则（内容向）

目标：用“模板 + 约束”批量产出订单，而不是手写每一单。

## 1. 订单类型配比（按章节）

- `story`：每章 6-10 单。强绑定关键人物/转折/选择。
- `normal`：每章 40-80 单。负责稳定的主循环收益与熟练度。
- `challenge`：每章 10-20 单。用于打断重复与制造峰值压力。
- `chain`：每章 1-3 条链（每条 3-5 单）。作为章节“器试/竞价/紧急交付”高潮。

## 2. 步骤数与节奏

- 前期（CH1）：3-4 步为主，单步 5-12 秒。
- 中期（CH2-CH3）：4-5 步为主，引入 1 个“变体步骤”。
- 后期（CH4-CH5）：5-6 步为主，每单必须带 1 个“挑战源”或“苛刻条件”。

## 3. 难度标签含义（统一语言）

- `tutorial`：几乎不失败；用来教学与建立爽感。
- `easy`：允许 1 次 `Poor`；奖励正常。
- `mid`：属性门槛/容错降低；奖励略高。
- `hard`：限时/连单/苛刻条件；奖励明显更高，且掉落更稀有。
- `story`：不以难度为目标，以展示与转折为目标。

## 4. 属性门槛用法

只在以下场景启用：

- 章节刚解锁新武器线，用 1-2 个门槛单逼玩家理解“属性差异”。
- 挑战单/连单的最后一单作为高潮门槛。

## 5. 掉落表（内容结构）

掉落表只需要三层：

- `DT-CHx-Ty`：章节 x、材料阶 y 的常规掉落
- `DT-STORY-CHx`：剧情单掉落（更偏图鉴碎片与文本碎片）
- `DT-CHAIN-CHx`：连单奖励（稀有配方/稀材）

## 6. 批量生成建议

先写好：

- 30-50 个 `order_templates.json` 模板
- 5 章的 `chapter_pacing.json` 解锁节奏
- 章节配比规则（本文件）

然后按章节循环批量生成订单：

1. 先生成 `story` 单（定锚）
2. 再用模板填充 `normal` 单
3. 最后插入 `challenge` 单与 `chain` 链条单（制造峰值）
```

内容制作建议：

- 先以 `order_templates.json` 作为订单生成母板（30-50 个模板足够覆盖前 5 章）。
- 每章先写 `story` 单定锚，再用模板填充 `normal` 单，最后插入 `challenge/chain` 做峰值。

## 33. 内容一致性护栏

本章目标：避免后续扩容“越做越散、越做越现代”。

### 33.1 内容基调与禁忌（正文）

```md
# 内容基调与禁忌表（内容护栏）

## 1. 核心关键词

- 主题：工坊、火、金属、名器、传承、选择
- 情绪：爽感（短）、执念（中）、抉择（长）
- 叙事落点：不是“历史模拟”，是“匠心成长”

## 2. 文案风格

- 句子短，少典故堆砌
- 角色说人话，避免“过度古风”
- 关键句允许有一两句“硬钉子台词”（记忆点）

## 3. 美术与道具禁忌（保持时代一致）

- 禁：现代螺丝/塑料件/LED 灯/现代字体招牌
- 可：铜、木、铁、皮、布，少量玉与金

## 4. 角色口癖（示例）

- 老掌柜：短句、硬、带训诫，“我教你打铁，不替你过日子。”
- 女商人：利落、会算账，但不油腻
- 对手坊主：嘲讽+现实主义，“客人认的是价、是快。”

## 5. 难度与情绪原则

- 前 10 分钟：允许玩家“几乎不失败”，先爽再收紧
- 中期：每章至少一次“高压峰值”（限时/连单/苛刻）
- 后期：高压来自规则变化，不是纯数值膨胀
```

### 33.2 命名规则与词表（正文）

```md
# 命名规则与词表（内容向）

## 1. 武器线命名

- `短刃`：口语、贴生活（猎户短刀/护院短刃）
- `长剑`：身份感（护院长剑/驿卒佩剑）
- `重剑`：力量感（断岳/镇关）
- `礼剑/礼器`：制度与权势（王都令/器坊制）

## 2. 材料命名

- 阶梯清晰：粗铁 < 熟铁 < 精钢 < 百炼钢 < 乌纹钢 < 陨铁
- 稀材带故事：陨铁、古代遗物碎片、宗门赠材

## 3. 地点与组织

- 地点：`王都`、`关城`、`集市`、`山矿`
- 组织：`器试司`、`宗门`、`兵坊`

## 4. 文本 Key 约定

- `TEXT-CHx-####`：主线对白
- `TEXT-EVT-####`：经营/事件
- `TEXT-END-####`：结局收束
```
